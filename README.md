# Virtual Slapper 👋💥

An interactive web application that allows users to simulate slapping a virtual face for comedic effect. Features multiple characters, dynamic reactions, sound effects, and progressive visual damage!

## Features

- 🎭 Multiple character types (Default, Nerd, Musician, Wizard, Joe Biden, Chef, Billionaire)
- 🎵 Sound effects for slaps, reactions, knockouts, and victory
- 💥 Dynamic visual feedback with particles and animations
- 📊 Progressive damage system with unique degradation paths
- 🎨 Character-specific backgrounds and victory animations
- 📱 Mobile-friendly with haptic feedback support

## Run Locally

**Prerequisites:** Node.js

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run the development server:
   ```bash
   npm run dev
   ```

3. Open your browser to `http://localhost:3000`

## Deploy to GitHub Pages

1. Install dependencies:
   ```bash
   npm install
   ```

2. Deploy to GitHub Pages:
   ```bash
   npm run deploy
   ```

The app will be built and deployed to `https://yourusername.github.io/Slapaguy/`

**Note:** Make sure GitHub Pages is enabled in your repository settings and set to use the `gh-pages` branch.
